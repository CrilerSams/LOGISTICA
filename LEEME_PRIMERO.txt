ACTUALIZACION PWA + ANDROID - LOGISTICA L2

Este paquete se agrega ENCIMA del repositorio que ya subiste.
No borres build.gradle, settings.gradle ni la carpeta app.

Archivos/carpetas a agregar o reemplazar:
- index.html
- manifest.webmanifest
- service-worker.js
- .nojekyll
- icons/
- .github/workflows/deploy-pwa.yml
- .github/workflows/build-apk.yml
- app/src/main/assets/index.html

Después:
1) GitHub > Settings > Pages > Source: GitHub Actions.
2) GitHub > Actions > Publicar PWA Logistica L2 > Run workflow.
3) Abre la URL HTTPS que aparezca al terminar.
4) iPhone/iPad: Safari > Compartir > Añadir a pantalla de inicio.
5) Android/laptop: botón Instalar app (o menú del navegador > Instalar).

La rama 'principal' ya está incluida en los workflows.
