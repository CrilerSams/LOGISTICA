LOGISTICA L2 - PWA UNIVERSAL

Archivos para subir directamente a la RAIZ del repositorio GitHub:
- index.html
- manifest.webmanifest
- service-worker.js
- .nojekyll
- carpeta icons

No usar GitHub Actions para esta primera puesta en marcha.
Publicacion simple:
Settings > Pages > Build and deployment > Source: Deploy from a branch > principal > /(root) > Save.

Luego abre la URL de GitHub Pages:
- iPhone/iPad: Safari > Compartir > Añadir a pantalla de inicio.
- Android: Chrome > Instalar app / Añadir a pantalla de inicio.
- Laptop: Chrome/Edge > Instalar aplicación.

La app funciona offline después de cargarla al menos una vez y conserva el banco de 336 preguntas dentro de index.html.
